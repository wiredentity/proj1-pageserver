# Proj1-pageserver
A simple webserver used to create an understanding of basic web architecture

# How-To
Use Docker to host webserver. Go to `localhost:openport/request` to request file. Supports html and css files.


To test, use `./tests/sh (ip:openport)` to run test scripts in the tests folder included in this repository.
